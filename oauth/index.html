OAuth 학습 목차

MCP 서버의 OAuth를 공부하는 학습 자료로, 일반 OAuth와 fastmcp OAuthProxy의 차이를 중심으로 다룬다.

용어집의 뜻은 그 문서 안에서만 유효하다. 예를 들어 1편은 인가 서버와 IdP를 따로 정의하지만, 2편과 3편은 IdP를 토큰을 발급하는 외부 서비스로 정의한다. 프록시 구조에서는 프록시도 토큰을 발급한다는 점에 주의해야 한다.

문서 목록

뒤 문서는 앞 문서의 용어와 구조를 안다고 가정하므로 번호 순서대로 읽기를 권한다.

번호문서다루는 내용
01role과 scope, 그리고 fastmcp OAuthProxyrole과 scope의 흐름, MCP 권한 스펙의 PRM·CIMD·DCR, 프록시가 바꾸는 다섯 가지, 우리 플랫폼의 scope 경로
02JWKS와 introspection서명의 두 방식, JWKS와 introspection의 차이, 취소 반영 시점, 우리 MCP 서버의 두 검증 지점과 검증 캐시
03JWT와 IdP 토큰의 구성JWT 구조와 등록 claim, 토큰 응답, access·ID·refresh token, IdP별 claim, fastmcp 토큰의 구조
04issuer, audience, jwks_uri세 설정 값의 뜻과 비교 방식, IdP별 값, 키 교체와 캐시, 내부 주소와 외부 주소, fastmcp JWTVerifier의 동작
05ID-JAG여러 MCP 서버의 로그인을 IdP 한 번으로 줄이는 흐름, token exchange와 JWT bearer grant, ID-JAG claim, 보안과 운영, fastmcp와 MCP SDK 코드, 우리 플랫폼 적용 추천
06우리 플랫폼의 MCP 인증 흐름프록시와 IdP의 역할 차이, 로그인과 MCP 요청 순서도, Redis에 저장하는 값, ID-JAG와 비교, 사용자 단위 토큰 공유와 게이트웨이 방식, ID-JAG를 넣을 때의 backend 토큰 문제
