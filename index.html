AI Agent와 그 주변 기술을 공부하면서 정리한 학습 자료다. 주제별로 묶었고, 시리즈는 번호 순서대로 읽으면 된다.

RAG

  • 1RAG 학습 자료 1부기초부터 검색까지 다룬다. 임베딩, 청킹, 벡터·키워드·하이브리드 검색, 재순위, 벡터 인덱스.
  • 2RAG 학습 자료 2부심화와 실무를 다룬다. 질의 변환, 실패 진단, 운영 주의점, 평가, 심화 기법.

평가

  • 1Agent 평가(eval) 입문QA 정답 대조에서 eval 프레임워크까지 다룬다. 데이터셋, 실행기, 채점기.

OAuth

  • 0OAuth 학습 목차MCP 서버의 OAuth를 다루는 6편의 목록과 읽는 순서.
  • 1role과 scope, 그리고 fastmcp OAuthProxyrole과 scope의 흐름, MCP 권한 스펙의 PRM·CIMD·DCR, 프록시가 바꾸는 것.
  • 2JWKS와 introspection서명의 두 방식, 두 검증 방법의 차이, 취소 반영 시점.
  • 3JWT와 IdP 토큰의 구성JWT 구조와 등록 claim, access·ID·refresh token, IdP별 claim.
  • 4issuer, audience, jwks_uri세 설정 값의 뜻과 비교 방식, 키 교체와 캐시, fastmcp JWTVerifier의 동작.
  • 5ID-JAG여러 MCP 서버의 로그인을 IdP 한 번으로 줄이는 흐름과 token exchange.
  • 6우리 플랫폼의 MCP 인증 흐름프록시와 IdP의 역할, 로그인과 MCP 요청 순서도, ID-JAG와 비교.

ToolHive

  • 0ToolHive 학습 목차ToolHive를 기초부터 내부 구조까지 다루는 10편의 목록과 읽는 순서.
  • 1ToolHive 개요와 첫 실행ToolHive가 푸는 문제, 구성 요소 지도, 배포 모드, 첫 실행.
  • 2실행 모델: workload, transport, proxyworkload 상태, RunConfig, transport별 proxy 구현, 원격 서버.
  • 3격리와 secret, 공급망 보안권한 프로필, 네트워크 격리, 컨테이너 보안 기본값, secret, 이미지 검증.
  • 4registry, 그룹, 클라이언트 설정registry 형식, registry server, 그룹, 클라이언트 설정 편집.
  • 5인증과 인가access token 검증, 내장 인가 서버, 나가는 인증, Cedar 인가.
  • 6관측, 감사, 사용 제한middleware 순서, trace와 metric, 감사 로그, 사용 제한, webhook.
  • 7Kubernetes operatorcontroller, CRD 카탈로그, MCPServer reconcile, 운영.
  • 8vMCP와 optimizerbackend 발견, 집계와 이름 충돌, 세션, composite tool, optimizer.
  • 9skill과 pluginskill 배포 흐름, lock file과 신뢰 모델, AI plugin 수명 주기.
  • 10우리 MCP 플랫폼과 비교구성 요소 대응, Kubernetes 객체 비교, 인증과 관측의 차이.
  • +ToolHive와 agentgateway 비교MCP gateway와 AI gateway의 차이, 기능별 비교와 선택 기준.

  • 1MCP 서버 구현 1부: FastMCP 서버의 기본 구조최소 구조, 파일과 디렉터리 배치, tool·resource·prompt 등록, 인증과 middleware를 추가하는 자리.
