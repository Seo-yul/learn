# learn

AI Agent와 RAG를 공부하며 정리한 학습 자료다. GitHub Pages로 배포한다.

- 사이트: https://devops.ai.kr/learn/

| 페이지 | 내용 |
|---|---|
| [rag-1.html](rag-1.html) | RAG 1부: 임베딩, 청킹, 검색, 재순위, 벡터 인덱스 |
| [rag-2.html](rag-2.html) | RAG 2부: 질의 변환, 실패 진단, 운영 주의점, 평가, 심화 기법 |
| [eval-intro.html](eval-intro.html) | Agent 평가(eval) 입문 |

## 페이지 추가

1. 단일 HTML 파일을 저장소 루트에 영문 파일명으로 둔다.
2. `index.html`의 목록에 링크를 한 줄 추가한다.
3. `main`에 push하면 배포된다.
